# Application Security Engineer
Remote (United States)

## About Tessellate
Tessellate is a B2B scheduling platform. Security sits inside engineering here, not
outside it, which means you will spend more time building than auditing.

Applicants must qualify as a U.S. Person as defined by ITAR (22 CFR 120.15).

## What you'll do
- Review designs and code for security issues before they ship
- Build tooling that catches classes of bugs automatically
- Run our vulnerability disclosure process
- Teach — office hours, internal writeups, and threat modeling sessions

## Requirements
- 5+ years in software engineering, with meaningful application security work
- Ability to read code in at least two of Python, Go, and TypeScript
- Practical knowledge of web application vulnerability classes
- Judgment about severity and real-world exploitability

## Nice to have
- Experience building static analysis or fuzzing tooling
- Cloud security experience, particularly AWS
- Public research or CVE credits

## Benefits
- Health, dental, and vision coverage
- Four weeks of paid time off
- Training budget
- Home office stipend
