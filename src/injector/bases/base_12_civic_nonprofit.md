# Software Engineer
Remote (United States)

## About Open Commons
Open Commons is a nonprofit that builds public records tooling for local journalists and
researchers. Everything we make is open source.

## What you'll do
- Build ingestion and search tools for public records datasets
- Work with journalists to understand what they actually need
- Maintain public APIs used by newsrooms and civic groups
- Contribute back to the open source libraries we depend on

## Requirements
- 3+ years building web applications
- Strong Python, ideally with Django or FastAPI
- Experience with search, whether Elasticsearch, OpenSearch, or Postgres full text
- Comfort working in the open, including public code review

## Nice to have
- Prior civic technology or newsroom experience
- Interest in document processing and OCR
- Open source contribution history

## Benefits
- Health, dental, and vision coverage
- Four weeks of paid time off
- Professional development budget
- Sabbatical after four years
